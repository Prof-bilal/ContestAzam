# CODE_STYLE.md — Coding Conventions

## C# (Backend)

- `PascalCase` public, `camelCase` private, `_` prefix private fields.
- Async suffixed with `Async`.
- One class per file.

## TypeScript/React (Frontend)

- Functional components only, `PascalCase` filenames.
- Props typed with interfaces.
- Hooks: `use` prefix.
- 2 spaces indent, single quotes, semicolons.

## Tests

- C#: `Arrange/Act/Assert`, `MethodName_Scenario_ExpectedResult`.
- React: `describe/it` blocks, `expect` assertions.
