# SECURITY.md — Security Rules

## Authentication

- **MVC**: Cookie authentication (browser sessions).
- **API**: JWT Bearer authentication.
- **Identity**: ASP.NET Core Identity for user management.
- Passwords hashed by Identity (PBKDF2).

## Authorization

- Roles: `Admin`, `Organizer`, `Participant`.
- `[Authorize]` on protected controllers/actions.
- User can only access their own resources.

## Secrets

> Never place secrets, API keys, passwords, tokens, private credentials, or production connection strings into source code or documentation.

- Use `appsettings.json` with placeholders.
- Use User Secrets for local development.
- Use Environment Variables in production.

## CSRF Protection

- All POST forms use `[ValidateAntiForgeryToken]`.
- Anti-forgery tokens generated by ASP.NET Core.

## XSS Prevention

- Razor Views auto-encode output by default.
- Use `@Html.Raw()` only with trusted content.

## SQL Injection

- Entity Framework Core uses parameterized queries.
- Never use raw SQL with string concatenation.

## Input Validation

- Model validation attributes on DTOs and ViewModels.
- Server-side validation on all forms.
- Client-side validation via jQuery Unobtrusive.

## Security Checklist

- [ ] No secrets hardcoded
- [ ] Input validated
- [ ] Authorization attributes present
- [ ] Anti-forgery tokens on forms
- [ ] No raw SQL concatenation
- [ ] Sensitive data not logged
- [ ] No XSS vectors
